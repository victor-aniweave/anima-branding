# Logo 檔案索引與使用規則

沿用現有檔名，實體檔案存放並公開於 GitHub：[github.com/victor-aniweave/anima-branding](https://github.com/victor-aniweave/anima-branding)（public repo）。每一版都是獨立的正式檔案，不可自行拼裝標誌與標準字的其他排列方式，也不可改變兩者之間的相對比例與間距。

選色的判斷順序：**先看背景是淺色或深色 → 再看這個版位需不需要品牌色 → 最後才決定用彩色版還是單色版。**

**Base URL**（每個檔名皆同時有 `.svg` 與 `.png`，將檔名接在後面即可直接取用）：
```
https://raw.githubusercontent.com/victor-aniweave/anima-branding/main/anima-brand/assets/logo/
```
例：`{Base URL}ANIMA_horizontal_primary.svg`

## 安全空間與最小尺寸

- 標誌四周需保留足夠淨空間，淨空間內不可放置其他文字、圖像或裝飾線條。
- 水平與垂直組合的淨空間比例不同，需分開對照（見主文件 01 章節示意圖）。
- 淨空間單位 A ＝標準字字高，屬相對單位，隨標誌整體等比例縮放，**不是固定 px 值**。以最小顯示尺寸反推：1A ≈ 13px，0.5A ≈ 6.5px；標誌放大時淨空間隨同一比例放大，不可用固定 px 套用在不同尺寸上。
- 數位介面最小寬度：24px（水平組合）。
- 印刷品最小寬度：20mm。

## 可以／不可以

| 可以 | 不可以 |
|---|---|
| 在淺色或深色的純色背景上使用標誌，維持足夠對比 | 把標誌放在複雜圖片、漸層或低對比背景上，導致線條糊掉 |
| 依比例等比例放大縮小標誌 | 拉伸、壓扁、旋轉標誌，或單獨拆開三道線條使用；不可自行拿 Textlogo 跟 Logomark 組合成新排列方式 |
| 在需要單色印刷或浮水印時，使用墨色或白色單色版本 | 更換標誌主色為藍色系以外的顏色，或加上陰影、外光暈等效果 |
